# Wine

마신 와인을 기록하는 개인 와인 노트입니다. → https://witchveronica88.github.io/wine/

## 구성

- `data/wines.json`: 와인 기록 전체예요. 모든 기기가 이 파일을 함께 봅니다.
- `photos/`: 와인 병 사진(`NNN.webp`)과 목록용 작은 사진(`NNN-thumb.webp`)
- `data/notes.json`: 와인 노트(품종·산지·기초 개념) 목록
- `index.html`: 앱 화면

## 와인 추가하기

Claude에게 아래 양식을 채워서 보내면 돼요. **사진과 마신 날만 있으면 되고**, 나머지는 아는 것만 적으면 됩니다.

```
사진: 라벨 앞면 (뒷면이 있으면 같이)
마신 날: 2026-10-21
마신 곳:
별점: 5점 만점, 0.5 단위
한줄평:
메모: 함께 먹은 음식, 같이 마신 사람 등
산 곳·가격:
```

- **내가 적는 것**: 마신 날 · 마신 곳 · 별점 · 한줄평 · 메모 · 산 곳·가격. 별점과 한줄평은 와인을 펼치면 사진 바로 아래에 나와요.
- **Claude가 채우는 것**: 라벨 정보(이름 · 생산자 · 지역 · 품종 · 빈티지 · 도수 · 용량), 시음 노트, 점수, 구매 판단, 조사 메모.

자세한 규칙은 `CLAUDE.md`의 "입력 규칙"에 있어요. 추가된 와인은 모든 기기에 바로 나타납니다.
